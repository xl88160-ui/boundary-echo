# 边界回响 · BOUNDARY ECHO

一款手机优先的俯视角竞技动作游戏原型。

## 当前版本
- 六名可选作战单位：夜枭、重锤、幻影、磁暴、猎隼、医官
- 手机虚拟摇杆与触控射击、闪避、技能
- 电脑键鼠操作
- 敌方 AI、逐渐增强的波次、击倒计数与芯片奖励
- 针对窄屏、横屏和折叠屏做响应式适配

## 试玩
启用 GitHub Pages 后访问：
https://xl88160-ui.github.io/boundary-echo/

## 操作
手机：左侧摇杆移动，右侧射击/技能/闪避。
电脑：WASD 移动、鼠标瞄准与射击、空格闪避、E 释放技能。

## 开发路线
1. 打磨战斗手感、地图与装备系统
2. 增加英雄成长、局内商店与战术目标
3. 加入房间系统、好友邀请与实时联机
4. 增加战绩、排行榜与赛季机制

当前版本为本地人机试玩，尚未接入在线多人服务端。
